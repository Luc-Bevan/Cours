## Changements pédagogiques

### Français
- Changement majeur sur la notation : elle se fait désormais sur le **temps passé sur Projet Voltaire**.

### Gestion de projet
- Probable refonte : au lieu de simplement « prétendre » faire un projet, les étudiants iront **jusqu'à la réalisation concrète** du projet.

### Git
- L'apprentissage de Git sera **moins poussé** qu'avant.
- Il est souhaitable que les étudiants fournissent un **travail personnel** dessus.
